Static data loaded once at import (no per-call file I/O):
----------------------------------------------------------
  promoters_proteincoding.dnatree  →  Promoter region lookup
  exons_proteincoding.dnatree      →  Exon region lookup
  genes_proteincoding.dnatree      →  Gene/intron region lookup
  gene_df.tsv                      →  Nearest gene distance computation
  ccres.dnatree                    →  cCRE overlap lookup
  variants.pkl.gz                  →  OpenTargets allele frequencies
